# Samples

Local sample files are grouped by subject. Paths below are repository-relative.

## US Constitution

The US Constitution

- `samples/constituion/us-constitution.html`: HTML export of [The Constitution of the United States](https://docs.google.com/document/d/1qFBWFmyFPxTn3cqXgMqXFX4zyzUWSzM2uCTp9PyXPtc/edit?tab=t.0#heading=h.9b3tsuuxglxb) (`1qFBWFmyFPxTn3cqXgMqXFX4zyzUWSzM2uCTp9PyXPtc`), the application's default document.

## Housing

Discussion from Laurie's Housing Class.
